# 🚀 FIRST TIME PROJECT RUN COMMANDS

Follow these direct commands in your terminal (VS Code / CMD / PowerShell):

---

### Step 1: Install Project Dependencies (First Time Only)
```powershell
npm install
```

---

### Step 2: Add API Key (Optional / If Needed)
Open `.env` file in VS Code and add your Gemini API Key if required:
```env
GEMINI_API_KEY="your_api_key_here"
APP_URL="http://localhost:3000"
```

---

### Step 3: Run Development Server
```powershell
npm run dev
```

---

### Step 4: Open in Browser
Click or open this URL in your web browser:
👉 **`http://localhost:3000`**

---

### 🛑 How to Stop Server Later:
Press **`Ctrl + C`** in terminal, then type `Y` and press Enter.
